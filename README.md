# Vertex 20.1

**Vertex** — приватный клиент для DDNet (DDraceNetwork), сфокусированный на автоматическом движении и избегании фриза. Построен на базе исходников DDNet 20.1, сборка через CMake.

> Репозиторий приватный. Доступ — по приглашению (Settings → Collaborators).

## Возможности

### Avoid-движок

Основной модуль клиента. Следит за тем, чтобы персонаж не оказался во фризе, и управляет движением автоматически.

| Режим | Описание |
|---|---|
| **Basic** | Лёгкий режим: простая инверсия направления при близости фриза. Без предикта других игроков, без симуляции. |
| **Blatant** | Полный автопилот: копия мира и симуляция по тикам, предикт игроков, автохук, учёт телепортов, unfreeze-логика. |

Включение и выключение авойда — **только биндом** (`avoidfreeze 1/0`). Выбор режима — в HUD-меню; переключение режима не влияет на включённость движка.

### Модули Blatant-режима

| Модуль | Что делает |
|---|---|
| Предикт игроков | Экстраполирует позиции других игроков по их инпуту и Velocity — симуляция не «натыкается» на уже ушедших игроков |
| NSIF | Not Slide In Freeze — не даёт затянуть себя во фриз инерцией скольжения |
| Автохук | Автоматический хук для экстренной остановки перед фризом |
| Направление | Инверсия направления input при предсказанном столкновении |
| Телес | Учёт телепорт-тайлов при прокрутке симуляции |
| Death | Чек смертельных тайлов (kill-тайлов) в траектории |
| Unfreeze | Автопозиционирование на unfreeze-тайл + окно ожидания в тиках |
| Анти-AFK | Игроки, стоящие на месте дольше N секунд, исключаются из симуляции |

### Aimbot-стек

| Функция | Что делает |
|---|---|
| Blatant aimbot | Мастер-выключатель аимбота в Blatant-режиме |
| Сегменты | Точность предсказания цели: луч разбивается на 1–64 сегмента |
| FOV | Конус захвата цели, 10–360 градусов |
| AutoAim | Автоматический захват ближайшей цели в конусе |
| AimAssist | Мягкая подстройка прицела к предсказанной точке |
| TrackPoints | Слежение за расчётными точками упреждения по цели |
| SafeAimTracking | Фильтрация точек трекинга (без наведения сквозь стены) |
| DrawTrackPoint | Визуализация точек трекинга |
| DrawAimbot | Визуализация лучей и конуса аимбота |

## Принцип работы

### Копия мира

При активном Blatant-режиме клиент держит локальный снимок игрового мира вокруг персонажа: тайлы (фриз, kill, телепорты, unfreeze-метки) и состояния остальных игроков. Копия обновляется каждый тик из данных коллизии, но не влияет на реальную игру — по ней только «прогоняется» будущее.

### Симуляция по тикам

Движок прогоняет виртуальные тики вперёд с текущим input:

1. Снимок мира копируется в симуляционный буфер.
2. Прогоняется `CheckTicks` тиков (по умолчанию 26) с текущим направлением и Velocity.
3. Если симуляция предсказывает попадание во фриз — за `KickInTicks` тиков до столкновения инвертируется направление (или срабатывает автохук).
4. Симуляция учитывает инерцию, хук, телепорты и предсказанные позиции других игроков.

Глубина горизонта (CheckTicks) и окно реакции (KickInTicks) настраиваются слайдерами 1–50.

### Предикт игроков

Позиции других игроков экстраполируются по их последнему инпуту и Velocity на глубину симуляции. Так движок не «объезжает» игрока, который уже уехал, и наоборот — вовремя реагирует на летящего навстречу.

Подробнее: [docs/AVOID_ENGINE.md](docs/AVOID_ENGINE.md), [docs/AIMBOT.md](docs/AIMBOT.md).

## HUD-меню

Меню настроек собрано из карточек в две колонки-masonry (карточка автоматически попадает в более короткую колонку).

- Карточка **«Режим Avoid»** — на всю ширину окна, пилюли **Basic / Blatant** по центру.
- Пилюля выбирает активный агент, но **не включает/выключает** авойд — это делает только бинд.
- Повторный клик по уже активной пилюле — no-op (защита от случайного переключения).
- При выборе Blatant ниже пилюль разворачивается блок его настроек: предикт, CheckTicks, KickInTicks, автохук, телепорты, unfreeze, aimbot-стек, визуализация.
- У Basic настроек нет — это осознанное решение: режим максимально простой.

## Бинды и команды

```
avoidfreeze 1        # включить avoid-движок
avoidfreeze 0        # выключить
bind f1 "avoidfreeze 1"
bind f2 "avoidfreeze 0"
```

Все параметры доступны и как конфиги: `cl_avoid_*` — см. таблицы в docs/.

## Сборка из исходников

Windows, Visual Studio 2022 + CMake:

```
git clone <url> Vertex-20.1
cd Vertex-20.1
cmake -B build
cmake --build build --config Release --parallel
```

Исполняемый файл: `build\DDNet.exe`. Запускать **из корня репозитория** — рядом должна лежать папка `data/`.
