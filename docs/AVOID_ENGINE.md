# Avoid-движок (KRX-glue)

Ядро Vertex. Задача движка — **не дать игроку упасть во фриз** и автоматически управлять движением в опасных ситуациях.

## Режимы

| Агент | Описание |
|---|---|
| Basic | Простая инверсия направления при близости фриза. Без симуляции и предикта. |
| Blatant | Полный автопилот на копии мира с тиковой симуляцией. |

Внутреннее поле `AvoidAgentType` поддерживает 5 агентов (basic, legit, blatant, fent, pilot), в HUD-меню открыты Basic и Blatant.

Вкл/выкл движка — только консольной командой / биндом:

```
avoidfreeze 1    # включить
avoidfreeze 0    # выключить
```

## Общая схема Blatant-режима

Каждый тик движок проходит три фазы:

```
[1] СНИМОК МИРА            [2] СИМУЛЯЦИЯ                [3] КОРРЕКЦИЯ
────────────────           ─────────────────            ─────────────────
копия тайлов вокруг    →   прокрутка CheckTicks     →   если предсказан фриз:
позиции игроков            виртуальных тиков            инверсия input за
Velocity, хук, инерция     с текущим input              KickInTicks тиков
```

### Фаза 1: снимок мира

Из данных коллизии (`CCollision`) берётся компактный снимок окрестности персонажа:

- тайлы фриза, kill-тайлы, телепорты, unfreeze-метки;
- позиции и Velocity остальных игроков;
- собственное состояние: скорость, активный хук, направление.

Снимок хранится в плоских массивах (`std::vector` фиксированной длины на тик) и полностью изолирован от реального игрового состояния — симуляция не может «сломать» игру.

### Фаза 2: симуляция по тикам

По снимку прогоняются виртуальные тики (игра идёт с фиксированным шагом 50 тиков в секунду):

- интегрируется движение с учётом инерции и трения;
- применяется текущий input (направление, джамп, хук, файр);
- тайлы обрабатываются как в реальной игре: фриз останавливает, телепорт переносит, kill убивает;
- позиции других игроков экстраполируются их последним инпутом (предикт).

Глубина горизонта — `CheckTicks` тиков (1–50, по умолчанию 26, ≈ полсекунды вперёд).

### Фаза 3: коррекция

Если на каком-то виртуальном тике симуляция попадает во фриз:

- вычисляется «ударная» точка и тик столкновения;
- за `KickInTicks` тиков до столкновения (окно реакции, 1–50) инвертируется направление input;
- при включённом автохке вместо/вместе с инверсией выпускается хук для жёсткой остановки;
- NSIF дополнительно гасит боковое скольжение, чтобы инерция не затянула во фриз по дуге.

## Модули

### Предикт игроков (`AvoidPlayerPrediction`)

Экстраполяция чужих позиций по их инпуту и Velocity на всю глубину симуляции. Без предикта движок шарахается от игроков, которые уже ушли с траектории; с предиктом — реагирует только на реально мешающих.

### Анти-AFK (`AvoidAfkProtection`, `AvoidAfkTime`)

Игроки, не двигавшиеся дольше `AvoidAfkTime` секунд (5–300), исключаются из предикта как препятствия — они стабильно стоят и их можно просто объехать по расчётной траектории.

### Автохук (`AvoidBlatantHook`)

Автоматический выстрел хуком в безопасную поверхность для экстренной остановки, когда инверсии направления недостаточно (высокая скорость, узкий коридор).

### Направление (`AvoidBlatantDirection`)

Инверсия направления движения — основной механизм коррекции. Отключается, если хочется положиться только на хук.

### Телесы (`AvoidBlatantTeles`)

Учёт телепорт-тайлов в симуляции: виртуальный тик, наступивший на телепорт, переносится в точку выхода. Без этого флага движок «не знает», что после телепорта фриза нет, и зря тормозит.

### Death-чек (`AvoidBlatantDeath`)

Симуляция проверяет не только фриз, но и kill-тайлы. Траектория, ведущая в смерть, считается опасной и корректируется так же, как траектория во фриз.

### Unfreeze (`AvoidBlatantUnfreezeTile`, `AvoidBlatantUnfreezeTicks`)

Если игрок всё же оказался заморожен: движок ведёт его к ближайшему unfreeze-тайлу (метка выхода из фриза). `AvoidBlatantUnfreezeTicks` (0–30) — окно ожидания в тиках перед следующим перемещением.

### Aimbot-интеграция

В Blatant-режиме параллельно работает aimbot-стек — см. [AIMBOT.md](AIMBOT.md).

## Конфиги

| Конфиг | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| `AvoidFreeze` | 0/1 | — | Мастер-вкл движка (команда `avoidfreeze`) |
| `AvoidAgentType` | 0–4 | 0 | Активный агент: 0 basic, 1 legit, 2 blatant, 3 fent, 4 pilot |
| `AvoidPlayerPrediction` | 0/1 | 1 | Предикт игроков |
| `AvoidNsif` | 0/1 | — | Not Slide In Freeze |
| `AvoidBlatantCheckTicks` | 1–50 | 26 | Горизонт симуляции, тики |
| `AvoidKickInTicks` | 1–50 | — | Окно реакции до столкновения, тики |
| `AvoidBlatantDirection` | 0/1 | — | Инверсия направления |
| `AvoidBlatantHook` | 0/1 | — | Автохук |
| `AvoidBlatantTeles` | 0/1 | — | Учёт телепортов |
| `AvoidBlatantDeath` | 0/1 | — | Чек kill-тайлов |
| `AvoidBlatantUnfreezeTile` | 0/1 | — | Автоход на unfreeze-тайл |
| `AvoidBlatantUnfreezeTicks` | 0–30 | — | Окно unfreeze, тики |
| `AvoidAfkProtection` | 0/1 | — | Анти-AFK |
| `AvoidAfkTime` | 5–300 | — | Порог AFK, секунды |
| `AvoidDebug` | 0/1 | — | Отладочный вывод |

## Legacy: VxAf

В клиенте остался старый avoid-движок (`VxAf*`-конфиги). Он функционально перекрыт KRX-glue и оставлен для совместимости; при переключении агента в HUD-меню старый движок автоматически гасится (`VxAfEnable = 0`, `VxAfBlatant = 0`). Новому коду рекомендуется пользоваться только `Avoid*`-конфигами.
