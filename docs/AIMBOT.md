# Aimbot-стек

Модуль автоматического прицеливания, работающий в связке с Blatant-режимом avoid-движка. Задача — наведение на игроков с учётом их движения (упреждение) и геометрии карты (не целиться сквозь стены).

## Общая схема

```
[ЦЕЛЬ]  →  [ПРЕДСКАЗАНИЕ]  →  [ФИЛЬТР]  →  [НАВЕДЕНИЕ]  →  [ВИЗУАЛИЗАЦИЯ]
выбор в     экстраполяция     конус FOV,   подстройка      лучи, точки,
конусе      на N сегментов    стены,       прицела         конус
FOV         вперёд            safe-track
```

## Компоненты

### Сегменты предсказания (`AvoidAimbotSegments`, 1–64)

Луч до цели разбивается на сегменты. Чем больше сегментов, тем точнее проверка траектории: для каждого сегмента отдельно проверяется пересечение со стенами и рассчитывается точка упреждения. 64 сегмента — попиксельная точность на дистанции средней карты, 8–16 достаточно для ближнего боя.

### FOV (`AvoidBlatantFov`, 10–360)

Конус захвата цели в градусах относительно текущего направления прицела. Цели вне конуса не захватываются. 360 — круговой захват.

### AutoAim (`AvoidAutoAimAimbot`)

Автоматический захват ближайшей (по углу к прицелу) цели внутри конуса FOV. Без ручного выбора цели.

### AimAssist (`AvoidAimAssistAimbot`)

Мягкий режим: не доворачивает прицел на цель мгновенно, а плавно подтягивает к предсказанной точке. Выглядит как «попадание с руки».

### Blatant aimbot (`AvoidBlatantAimbot`)

Жёсткий режим наведения: мгновенный доворот на предсказанную точку. Используется в связке с avoid-движком, когда важен результат, а не видимость честной игры.

### TrackPoints (`AvoidTrackPoints`)

Движок строит серию расчётных точек упреждения по ходу цели — по одной на сегмент предсказания. Наведение ведётся не «в игрока», а в трек-точку, где игрок окажется к моменту попадания.

### SafeAimTracking (`AvoidSafeAimTracking`)

Фильтр трек-точек: точка отбрасывается, если прямая до неё пересекает стену. Наведение выбирает последнюю «чистую» точку на траектории цели.

### Визуализация

| Конфиг | Что рисует |
|---|---|
| `AvoidDrawTrackPoint` | Трек-точки упреждения |
| `AvoidDrawAimbot` | Лучи наведения и конус FOV |

Визуализация помогает настраивать сегменты и FOV: сразу видно, какие точки отсекаются safe-фильтром.

## Математика

Ядро расчётов — векторная математика на `vec2`:

- **Упреждение**: `aim = target_pos + target_vel * t`, где `t` подбирается итеративно (сходимость за 2–3 итерации на типичных дистанциях).
- **Конус FOV**: цель внутри конуса, если `dot(normalize(target - me), aim_dir) > cos(fov/2)`.
- **Пересечение со стеной**: пошаговый марш по сегментам луча (`IntersectX` / `IntersectY` хелперы коллизии) — то же семейство функций, что использует физика игры.
- **Нормализация угла**: приведение разницы углов к `[-pi, pi]` перед плавным доворотом (AimAssist).

## Конфиги

| Конфиг | Диапазон | Описание |
|---|---|---|
| `AvoidBlatantAimbot` | 0/1 | Жёсткое наведение |
| `AvoidAimbotSegments` | 1–64 | Сегменты предсказания |
| `AvoidBlatantFov` | 10–360 | Конус захвата, градусы |
| `AvoidAutoAimAimbot` | 0/1 | Автозахват цели |
| `AvoidAimAssistAimbot` | 0/1 | Плавная подстройка |
| `AvoidTrackPoints` | 0/1 | Трек-точки упреждения |
| `AvoidSafeAimTracking` | 0/1 | Фильтр точек по стенам |
| `AvoidDrawTrackPoint` | 0/1 | Визуализация точек |
| `AvoidDrawAimbot` | 0/1 | Визуализация лучей и конуса |

Рекомендуемые пресеты: **легит** — Segments 8, FOV 60, AimAssist; **blatant** — Segments 32, FOV 180, Blatant aimbot + TrackPoints + SafeTracking.
